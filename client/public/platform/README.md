# Public platform screenshots

These images show real application interfaces with synthetic demonstration data and no production session or customer records. The workspace-only capture excludes the sidebar from the image pixels, including when downloaded or expanded.

The first four images were recovered intact from the saved review 4. `operaciones.png` is generated by `scripts/capture-public-operations.cjs` with intercepted local fixtures. Its source is the current repository base f599ae2. No public API endpoint or real user was modified.

Use CN_CHROMIUM_PATH for the browser executable and optionally CN_FONT_AWESOME_PATH for a local copy of @fortawesome/fontawesome-free@6.5.1. Build the client before running the capture script.
